# Project 1: The Empathy Map

**UI/UX Design Internship, DecodeLabs (Batch 2026)**
**Author:** Dr. Israel Fatunmibi

## Scenario
A fitness startup wants to launch an app for busy office professionals who struggle to find time to exercise. Before any design work, the goal is to understand the user's pain.

## My role
UX Researcher: define the target audience, create user personas, and build empathy maps.

## Deliverables
1. **User Personas** – three proto-personas (Funmi, Tunde, Chioma), with Funmi as the primary persona
2. **Empathy Maps** – Says, Thinks, Does, Feels for each persona
3. **Summary** – comparison of barriers, core needs and emotional states

## Key insight
Busy professionals don't need more motivation. They need a way to look after themselves that costs almost no time, energy or pressure.

## Note
These are proto-personas based on assumptions and are intended to be validated with user interviews. Incomes are fictional.
